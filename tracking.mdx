title: "Tracking"
description: "Your view of a shipment's progress, and the customer's."
---

There are two tracking views. Yours is authenticated and identifies the order. Your customer's is a link with no credentials and no identifiers in it.

## Your view

```bash
curl "$BASE_URL/api/v2/external/shipments/$SHIPMENT_ID/tracking" \
  -H "Authorization: Bearer $ACCESS_TOKEN"
```

Example response:

```json
{
  "id": "01a1933c-72ef-745d-af3d-eb836db7878c",
  "reference": "AT-1793471573-1",
  "status": "OUT_FOR_DELIVERY",
  "driverLocation": {
    "latitude": 24.76069,
    "longitude": 46.69400,
    "accuracyMetres": 8.00,
    "recordedAt": "2026-10-31T18:38:55.593234Z",
    "stale": false,
    "ageSeconds": 5
  },
  "locationStatus": "AVAILABLE",
  "recommendedRefreshSeconds": 15,
  "history": [
    { "status": "CREATED", "at": "2026-10-31T18:32:54.767375Z" },
    { "status": "ASSIGNED", "at": "2026-10-31T18:33:12.042301Z" },
    { "status": "PICKED_UP", "at": "2026-10-31T18:37:05.829953Z" },
    { "status": "OUT_FOR_DELIVERY", "at": "2026-10-31T18:37:11.585830Z" }
  ],

    "target": "DELIVERY",
    "estimatedArrivalAt": "2026-10-31T18:45:21.609533Z",
```

`history` lists the [statuses](/shipments#status) in order with the instant each was reached. `eta` follows the same rules as on the [shipment read](/shipments#read).

## The customer's view

Every shipment gets a tracking URL at creation (`trackingUrl`). The last path segment is the code:

```bash
curl "$BASE_URL/api/v2/public/tracking/$TRACKING_CODE"
```

No `Authorization` header — the 43-character code is the credential, so anyone holding the link can see progress. The view carries `status`, `driverLocation` (coarse), `locationStatus`, `recommendedRefreshSeconds`, and `history`, and no order reference, shipment id, merchant, recipient, pickup, or destination. Responses are `no-store` and rate limited; an unknown code answers `404 TRACKING_LINK_NOT_FOUND`.

## Location status

`driverLocation` is `null` unless a position is available. `locationStatus` says why:

| Status | Meaning |
| --- | --- |
| `NOT_ASSIGNED` | No driver offer yet |
| `WAITING_FOR_DRIVER_ACCEPTANCE` | Offered, not yet accepted |
| `LOCATION_UNAVAILABLE` | A driver is assigned but no position is available |
| `AVAILABLE` | A current position is available |
| `STALE` | A position is available but older than the freshness budget |
| `TERMINAL_NO_LIVE_LOCATION` | The shipment has ended |

<Warning>
  Never present a `STALE` position as the driver's current location — show "last seen" using `ageSeconds`.
</Warning>

## Polling

`recommendedRefreshSeconds` is `15` while a shipment is active and `30` once it has ended. Honour it; for state changes, use [webhooks](/webhooks).
