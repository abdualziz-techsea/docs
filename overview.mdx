The External API is the machine-to-machine surface of DropHub. A merchant system authenticates as an OAuth client, optionally quotes a price, creates a shipment from an order reference and two coordinates, and receives signed webhook events as the shipment moves.

## What you send

Everything DropHub needs to move a parcel:

```json
{
  "reference": "ORDER-1042",
  "pickup": { "savedLocationCode": "SANDBOX_PICKUP" },
  "destination": { "latitude": 24.774265, "longitude": 46.738586 },
  "recipient": { "name": "Noura", "mobile": "0551234567" }
}
```

## What DropHub derives

You do not model any of the following. DropHub resolves each one when the shipment is created:

| Derived | Meaning |
| --- | --- |
| Route and distance | Computed between pickup and destination |
| Price | Priced against your account's commercial terms, or frozen by a quote you pass |
| Carrier and driver | Selected and dispatched without your involvement |
| Defaults | One piece, 1 kg, described as "Parcel", SAR, prepaid — unless you say otherwise |
| Lifecycle state | Advanced by real events from the field |
| Tracking URL | Minted for you and returned on the create response |

## The whole surface

All paths start with `/api/v2`.

| Endpoint | Purpose |
| --- | --- |
| `POST /api/v2/oauth/token` | Exchange client credentials for a bearer token |
| `GET /api/v2/external/pickup-locations` | Your saved pickup locations and their hours |
| `GET /api/v2/external/coverage/areas` | The combined area DropHub delivers to |
| `POST /api/v2/external/quotes` | Price a delivery; the price is held for 15 minutes |
| `POST /api/v2/external/serviceability` | Check whether a pickup and destination can be served now |
| `POST /api/v2/external/shipments` | Create a shipment |
| `GET /api/v2/external/shipments/{id}` | Read a shipment |
| `PATCH /api/v2/external/shipments/{id}` | Change destination, recipient, or pickup window |
| `POST /api/v2/external/shipments/{id}/cancel` | Cancel before pickup |
| `GET /api/v2/external/shipments/{id}/tracking` | Progress, driver position, ETA, driver |
| `GET /api/v2/external/shipments/{id}/proof` | Pickup and delivery evidence metadata |
| `GET /api/v2/external/shipments/{id}/proof/{stage}/content` | Evidence image |
| `GET /api/v2/external/shipments/{id}/incidents` | Loss, damage, and failed-delivery incidents |
| `GET /api/v2/external/shipments/{id}/incidents/evidence/{assetId}` | Incident image |
| `POST`, `GET`, `PATCH`, `DELETE /api/v2/external/webhook` | Your single webhook |
| `POST /api/v2/external/webhook/secret-rotations` | Rotate the signing secret |
| `/api/v2/external/sandbox/…` | [Sandbox](/sandbox) controls — sandbox credentials only |
| `GET /api/v2/public/tracking/{code}` | The customer-facing tracking view, unauthenticated |

Responses are JSON. Errors are `application/problem+json`. Timestamps are UTC, ISO 8601, with microseconds. Money is a JSON number with two decimals in SAR (`34.00`). Fields without a value are present and `null`.
